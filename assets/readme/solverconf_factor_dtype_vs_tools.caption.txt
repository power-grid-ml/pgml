Agreement of pgml with each reference tool on an identical model, by pgml arithmetic precision. Before any solution is compared the model is proven identical in pgml and in the tool (admittance matrices, or linear probe solves where the tool exposes no matrix). Each marker is one grid: the largest difference of any complex node voltage in per unit between pgml's solution and the tool's own double-precision solve at tight tolerance (1e-12). The first level is pgml's reference configuration (double precision, CPU, tolerance 1e-12). The constant offset of the OpenDSS markers in double precision is OpenDSS's ten-digit degree-to-radian constant, which rotates its source by 3.4e-10 rad. Values in pu. double (complex128): pandapower median 2.2e-14, max 1.9e-12 (9 grids), power-grid-model median 4.1e-14, max 9.1e-13 (7 grids), OpenDSS median 3.4e-10, max 3.5e-10 (15 grids); mixed (double result): pandapower median 2.1e-14, max 1.9e-12 (9 grids), power-grid-model median 3.0e-14, max 9.1e-13 (7 grids), OpenDSS median 3.4e-10, max 3.5e-10 (15 grids); single (complex64): pandapower median 3.9e-6, max 2.2e-5 (9 grids), power-grid-model median 2.9e-6, max 2.0e-5 (7 grids), OpenDSS median 7.2e-6, max 7.9e-5 (15 grids).
